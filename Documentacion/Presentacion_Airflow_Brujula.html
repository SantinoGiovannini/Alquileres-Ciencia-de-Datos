01 · La idea central

¿Qué problema resuelve el proyecto?

Recolecta avisos de alquiler de Mendoza, los transforma a un formato común y entrega un dataset listo para analizar.

2

Fuentes

Inmoclick e InmoUP. Cada aviso publicado es una fila.

1

Unidad de análisis

El aviso, no necesariamente la propiedad. Una misma propiedad puede aparecer en dos portales.

1

Objetivo

Preparar precio_m2 para estimar el valor esperado y estudiar oportunidades.

Frase para la defensa: “El pipeline convierte publicaciones heterogéneas en una base comparable y trazable”.

Regla de dependencias

Una tarea empieza cuando la anterior termina correctamente. Si una falla, las siguientes no deberían procesar datos incompletos.

Qué hace Airflow

Coordina, agenda, ejecuta, registra estados y muestra logs. No es el scraper por sí solo.

03 · El entorno

Airflow coordina; Docker arma el equipo

airflow-apiserver

Sirve la interfaz web y la API en localhost:8080.

airflow-scheduler

Decide cuándo ejecutar y respeta dependencias.

airflow-worker

Ejecuta el código real de las tareas.

dag-processor

Lee los archivos Python de dags/.

Postgres

Guarda usuarios, ejecuciones, estados y metadata.

Redis

Funciona como cola de mensajes entre scheduler y worker.

Pregunta típica: ¿Por qué airflow-init termina? Porque solo inicializa la base y el usuario. Que termine con código 0 es normal.

06 · Ejecutar una prueba

Trigger: iniciar una corrida manual

Abrir el formulario no ejecuta nada. La ejecución empieza al confirmar el botón Trigger.

ParámetroEjemplo cortoPara qué sirve
max_paginas1Limita la cantidad de unidades de búsqueda por fuente.
fuentes["inmoclick"]Selecciona uno o ambos portales.
fecha20260909Elige la carpeta bronce AAAAMMDD.
Primera prueba recomendada: max_paginas=1, fuentes=["inmoclick"], fecha=20260909.

La fecha lógica ordena el historial de Airflow. El parámetro fecha elige los datos guardados en data/raw/: no son lo mismo.

07 · Qué hace cada etapa

Las funciones, en detalle

FunciónRecibeProceso principalDevuelve / guarda
extract_listingsParámetros: max_paginas, fuentes, fecha.Descarga listados y fichas. Conserva el HTML original. Si un portal falla, lo registra y continúa con el otro.Devuelve la carpeta data/raw/AAAAMMDD/. Falla solo si no quedó ningún aviso.
parse_rawLa carpeta bronce y las fuentes seleccionadas.Lee HTML/JSON-LD con el parser específico de cada portal y unifica el esquema de columnas.Guarda data/processed/_registros.json y devuelve su ruta, no miles de filas por XCom.
transform_cleanRuta del JSON y carpeta de la corrida.Crea la clave primaria, convierte tipos, calcula precio_m2, marca duplicados cruzados y valores sospechosos.Guarda data/processed/_intermedio_clean.csv y devuelve su ruta.
quality_checkRuta del CSV intermedio y carpeta de resultados.Comprueba unicidad, filas, forma, tipos, nulos y columnas 100% nulas. También resume fuentes, monedas y marcas.Guarda resultados/AAAAMMDD/quality_report.txt. Una advertencia queda registrada sin ocultarse.
export_csvCSV limpio, ruta del reporte y carpeta de la corrida.Ordena las columnas y genera el archivo final. Depende del reporte para entregar después del control.Guarda resultados/AAAAMMDD/brujula_inmobiliaria_alquiler_mendoza.csv.
Cómo se conectan: Airflow encadena las rutas devueltas por cada función: run_folder → registros_path → clean_path → report_path → CSV final. En el grafo, esas rutas aparecen como dependencias entre tareas.

10 · La etapa de modelado

¿De dónde sale el residuo?

No viene directamente del scraping. Se calcula después de entrenar un modelo de regresión.

precio_m2
real del CSV
−
precio_m2
esperado por el modelo
=
residuo
real − esperado

Ejemplo

Real: 12.000
Esperado: 10.000
Residuo: +2.000

Interpretación

Positivo: el modelo subestimó. Negativo: sobreestimó. Cerca de cero: predicción cercana.

Importante: el DAG actual llega hasta export_csv. El análisis del residuo es una etapa posterior de modelado.

11 · No confundir estados

Airflow conserva el historial

Ejecución roja histórica

smoke_20260909 falló por un caso de borde: en un dataset muy corto podía faltar una columna opcional.

Ejecuciones posteriores

smoke_20260909_v2 y la ejecución manual posterior terminaron correctamente.

Cómo diagnosticar:
docker compose ps · revisar el grafo · abrir la tarea · elegir Logs.

Que el resumen muestre una falla histórica no significa que la última ejecución esté fallando.

12 · Respuesta corta

Lo que conviene poder explicar

¿Qué es una fila?

Un aviso de departamento publicado en Inmoclick o InmoUP, no necesariamente una propiedad única.

¿Qué es la clave primaria?

fuente:usr_id-prp_id. El número de aviso solo no alcanza.

¿Por qué conservar el HTML?

Permite corregir la transformación y reprocesar sin volver a scrapear.

¿Qué hace quality_check?

Verifica unicidad, cantidad, forma, tipos, nulos y columnas completamente vacías.

¿Dónde está el entregable?

resultados/AAAAMMDD/: CSV final y quality_report.txt.

¿Qué es el residuo?

Valor real menos valor esperado por el modelo: sirve para clasificar sobrevalorado, de mercado u oportunidad.
